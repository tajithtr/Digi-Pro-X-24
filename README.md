# 🛒 Digi Pro X 24  
**Full-Stack E-Commerce Platform for Technology Products & IT Services**

Digi Pro X 24 is a **full-stack e-commerce web application** designed for selling electronics and technology products while also offering IT-related services online.  

Developed by **Tajith Rashidha Bandara Ekanayake** during his internship at **Fusion Wave Systems (Pvt) Ltd**, this project demonstrates practical industry experience in **modern e-commerce development, database integration, responsive design, authentication, security, SEO, and software quality practices.**
