Digi Pro X 24

Digi Pro X 24 is a full-stack e-commerce platform for electronics, technology products, and IT services.

The system was developed by Tajith Rashidha Bandara Ekanayake during his time working as a Software Engineer Intern at Fusion Wave Systems (Pvt) Ltd.

🚀 Key Features

- 🛒 Product browsing and e-commerce functionality
- 🔍 Product search and category-based navigation
- 🛍️ Shopping cart and checkout system
- 👤 Customer registration and authentication
- 🔐 Password management and secure session handling
- 📦 Order management and order tracking
- ⭐ Product reviews and ratings
- 💳 Payment and Cash on Delivery functionality
- 🌍 Country-based checkout and purchasing rules
- 🛠️ IT service request and booking functionality
- 📋 Service checkout and request management
- 👨‍💼 Administrative management features
- 📧 Email communication and notifications
- 📱 Responsive design for desktop, tablet, and mobile devices
- 🔎 SEO-friendly pages, sitemap, robots.txt, and structured metadata
